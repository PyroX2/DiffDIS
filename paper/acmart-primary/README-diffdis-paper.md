# DiffDIS DiT Paper

Main paper source:

```text
diffdis_dit_paper.tex
```

Bibliography:

```text
diffdis_dit_refs.bib
```

Compile from this directory with a LaTeX distribution installed:

```sh
pdflatex diffdis_dit_paper
bibtex diffdis_dit_paper
pdflatex diffdis_dit_paper
pdflatex diffdis_dit_paper
```

The file uses the local ACM class and bibliography style included in this template directory:

```text
acmart.cls
ACM-Reference-Format.bst
```

Before submission, replace the `TODO` author, affiliation, email, and acknowledgments placeholders.
